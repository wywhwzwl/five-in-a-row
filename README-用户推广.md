## 🌟 核心亮点

### 🎨 视觉体验
- **15×15 标准棋盘**：木质纹理底色 + 天元/四小目星标，复刻传统棋具质感
- **立体棋子**：径向渐变 + 左上高光点，每颗棋子都有"光打在上面的感觉"
- **悬停预览**：鼠标移到哪里，绿色圆环 + 四角定位块即时提示
- **落子动画**：弹性缩放效果，棋子"啪"地落定
- **胜利高亮**：五连瞬间触发红线穿过，胜负一目了然

### 🤖 三档 AI 对手
| 版本 | 难度 | 风格 | 适合 |
|------|------|------|------|
| **V1.0 随机** | ★☆☆ | 完全随机落子 | 纯娱乐 / 调试 UI |
| **V2.0 防御** | ★★☆ | 会识别并封堵你的活三、冲四 | 初学者练手 |
| **V3.0 评分** | ★★★ | 攻防权重综合评估，主动制造陷阱 | 进阶玩家挑战 |

> 💡 难度可在对局中**随时切换**，不用重新开始。

### ⚖️ 专业 Renju 规则
- ✅ 黑棋采用**国际禁手规则**：长连(≥6)、双四(双冲四)、双三(双活三) 均判负
- ✅ 白棋自由规则，连五即胜
- ✅ 严格遵守"**黑棋需恰好五胜**"——杜绝"乱拳打死老师傅"

### 🛠️ 完整对局控制
- **🔄 重新开始**：一键清空棋盘，棋谱保留用于复盘
- **↶ 悔棋**：一键回退**玩家+AI 两步**，不必步步为营
- **🗑️ 清空棋谱**：随时抹去记录，开启全新挑战
- **键盘快捷键**：`Ctrl+Z` 悔棋 / `Ctrl+R` 重开 / `1·2·3` 切难度

### 📜 棋谱记录
- 右侧实时棋谱面板，每一手自动追加
- 黑白棋子清晰区分，坐标精确显示
- 对局结束可回看完整步骤

## 🚀 30 秒上手

1. **双击 `index.html`** — 浏览器自动打开，无需任何安装
2. **点击棋盘** — 你的黑棋立即落下
3. **等 AI 回应** — 状态栏显示"🤖 AI 思考中"
4. **连成五子即胜** — 触发红线高亮与胜利提示

> 🎯 无需注册、无需联网、无需任何学习成本。
